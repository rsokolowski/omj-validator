# Patterns ("Wzorce") Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Students write problem-solving patterns (trigger → action), refine them with the AI in guided rounds, get OMJ tasks linked to them, and practise them with spaced repetition (self-rated recall cards + graded linked tasks).

**Architecture:** A new `app/patterns/` package (routes, service, pure `srs.py` and `linking.py`) mirroring `app/private_tasks/`, three new tables plus `submissions.pattern_id` (migration 007), three schema-constrained Gemini calls parsed in `app/ai/pattern_parsing.py`, one hook in the grading worker. Frontend: `/wzorce` pages plus a save/suggest box and practice banner on both task pages.

**Tech Stack:** FastAPI, SQLAlchemy 2.0 (<2.1), Alembic, PostgreSQL 16, google-genai (Gemini), Next.js 16 / React 19 / MUI v7, pytest (in-memory SQLite), Playwright + fake Gemini.

**Spec:** `docs/superpowers/specs/2026-09-29-patterns-design.md`

## Global Constraints

- Never commit OMJ statements; fixtures and fake-Gemini responses use invented problems only (CLAUDE.md).
- Owner-only: someone else's pattern / link / private task / submission → 404.
- Pattern field limits: trigger 5–300, action 5–600, example ≤1000, recall_text 10–1000, answer ≤1000, reason/why ≤300, comment ≤500, question ≤300, ≤2 questions, 2–3 variants, 1–3 suggestions, ≤5 links, ≤3 skills, ≤10 stored rounds.
- `ai_usage` kinds: `pattern_refine` (30/day), `pattern_suggest` (10/day), `pattern_link` (10/day); global cap `rate_limit_ai_usage_global_per_day`; allowlisted bypass; a made call counts even when it fails.
- Abuse threshold: `settings.private_abuse_threshold` (70) → 422 "Tej treści nie możemy przetworzyć."
- SRS: `INTERVALS = {1: (1, 4), 2: (7, 14), 3: (30, 90)}`, level 4 = maintenance, 180 days; dates are Europe/Warsaw calendar days.
- Retention: `retention_pattern_months` default 24 (prod 24, dev/e2e 0).
- UI copy in Polish; every user/AI text rendered through `MathContent`.
- Commits end with the session attribution lines.

## Review Focus

1. A second tab / double click on a rating button → the review counts once (conditional update; 409 for the loser). Test in Task 6.
2. A graded practice submission whose pattern was deleted before grading finished → grading completes, nothing raises (`pattern_id` NULL / pattern missing). Test in Task 5.
3. A pattern linked to a private task that is then deleted → the link disappears, the pattern survives and its detail still loads. Test in Task 1.
4. An OMJ key linked to a pattern that is no longer loaded (metadata removed) → detail shows `available: false`, practice never offers it. Test in Task 6.
5. The AI returns a task key outside the candidate list, or the same key twice → dropped, never stored. Test in Task 3/7.
